# Neon Rush: Street Legends
Free pseudo-3D arcade racing game. No coins, no ads. Works offline in any browser (PC, laptop, phone, tablet).
- 10 real cars/bikes (Mustang, BMW M4, GT-R, Huracan, Ninja H2, Thar...) with their own engine sounds
- 7 Indian themes (Mumbai night, Rajasthan, Ghats, Kerala rain, Delhi heat, Ladakh snow, Goa sunset)
- 15 levels: Race, Dash, Drift - harder as you go. Nitro, drift, keyboard / touch / gyro tilt
- Login with name + password (saved on each device), car + colour garage
## Play
Double-click `index.html`, or run `run.bat` (Windows) / `./run.sh` (Mac/Linux).
## Publish on GitHub
Upload all files -> Settings -> Pages -> Deploy from branch `main` / root. Share the link.
